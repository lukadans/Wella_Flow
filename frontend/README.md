# Wella Flow — Frontend sem React

Abra frontend/index.html em um navegador para testar. HTML/CSS/JavaScript puro, sem instalação.

Inclui: tema grafite/menta, cards em gradiente, responsividade, navegação desktop/mobile, filtros, pesquisa, favoritos e pedidos com quantidades. Favoritos e quantidades são armazenados no navegador. Importação local de JSON VTEX normaliza produto > SKU > vendedores > ofertas, sem alterar o arquivo nem enviar dados a servidor. Valores de site e comerciais são apresentados separadamente quando existirem.

Limitações: demonstrativos fictícios, sem Google Sheets, backend, Tauri, autenticação ou envio de pedido. O site chatgpt.site fornecido pelo usuário não é atualizado automaticamente via GitHub.
